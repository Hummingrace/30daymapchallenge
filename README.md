# 2024 #30DayMapChallenge
- Grace Delgado

This is a personal project for the 2024 #30DayMapChallenge, a daily social mapping project open to everyone. The challenge takes place every November, with 30 different mapping themes - one for each day of the month. 

![image](https://github.com/user-attachments/assets/a79b2355-a5f6-40a7-878c-199e1745ebc4)

My personal goal was to create 10 maps and learn about new datasets and mapping tools along the way. View more details at the official site for the challenge https://30daymapchallenge.com/.

Map images of my completed projects are hosted here: https://hummingrace.github.io/30daymapchallenge/
